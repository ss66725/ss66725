## 学习方法

- **按日期整理**：每天的练习放在一个文件夹里，文件夹名就是日期，例如 `261108` 表示 2026 年 11 月 8 日。
- **写 README**：每个文件夹都说明当天的内容和知识点，方便以后回看。
- **期望输出**：C 和 Python 的练习附有示例输入和正确输出，可以自动检查程序是否正确。
